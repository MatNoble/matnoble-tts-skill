## 🎚️ 参数微调经验法则 (Rules of Thumb)

1. **语速 (`speed`) 控制基准**：
   - 诗歌 / 纪录片 / 睡前故事：`0.88 ~ 0.95`
   - 标准新闻 / 教学讲解 / 客服：`0.98 ~ 1.02`
   - 短视频 / 播客闲聊 / 资讯快报：`1.05 ~ 1.15`
   - *注意：每调节 `±0.05` 即为听觉可感知的一档微调。*

2. **音调 (`pitch`) 控制基准**：
   - 男声增加厚重感 / 悬念：`-3Hz ~ -5Hz`
   - 女声增加亲和力 / 甜美：`+2Hz ~ +4Hz`
   - 疑问句与高亢惊喜：局部使用 `[pitch:+10%]` 或 `[pitch:high]`。

3. **风格强度 (`styledegree`) 基准**：
   - 微软默认强度为 `1.0`。
   - 推荐在 `1.2 ~ 1.5` 之间微调以增强戏剧表现力（例如 `style="cheerful:1.4"`）。
   - `> 1.8` 属于戏剧化极端情绪，除特定小品剧本外慎用。
