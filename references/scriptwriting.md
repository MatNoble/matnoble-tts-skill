# 配音导演指南：有声文稿润色与指令修饰技巧

作为 AI Agent，当用户要求你“把这段文字转成语音”、“帮我做一段配音”或“生成一段播客”时，**不要只是死板地把书面文字直接提交给 TTS**。

书面语（Written Text）与有声语言（Spoken Voice）有着本质的区别：
- 书面语依赖视觉断句、段落排版和标点符号；
- 有声语言依赖**呼吸节奏、情绪起伏、重音留白和特定发音**。

本指南指导你如何像一位专业“配音导演（Audio Director）”一样，使用 MatNoble-TTS 的行内语音指令（Inline Directives）对原始文稿进行艺术修饰与专业编排。

---

## 🎭 核心修饰手法与设计哲学

### 1. 呼吸感与转折留白 (`[pause]`)
**原则**：机器合成如果一口气读到底，会显得冰冷、局促。在关键节点主动制造留白，能大幅提升听感舒适度与悬念感。

- **情境 1：转折与逻辑跃迁前**
  - 在“但是”、“然而”、“换句话说”、“更关键的是”之前，插入 `[pause:300ms]` 到 `[pause:500ms]`，给听众心理预期。
  - *范例*：`这项技术的参数看起来非常亮眼，[pause:400ms]但是，它真正的杀手锏在于落地成本。`
- **情境 2：设问与自答之间**
  - 提出疑问后不要马上给出答案，插入 `[pause:600ms]` 制造悬念。
  - *范例*：`未来的 AI 交互到底会是什么形态？[pause:600ms]答案可能并不在对话框里。`
- **情境 3：段落或主题切换**
  - 一段核心论述结束后，加入 `[pause:800ms]` 或 `[pause:1s]`，让信息有沉淀时间。

### 2. 核心观点重音 (`[emphasis]`)
**原则**：平铺直叙的语音缺乏重点。使用 `[emphasis:strong]关键词[/emphasis]` 让 AI 模型在目标词汇上提高咬字力度与音量。

- **适用对象**：核心名词、关键结论、品牌名、行动号召（CTA）。
- *范例*：`这不仅仅是一次简单的升级，而是[emphasis:strong]彻底重构了底层架构[/emphasis]。`
- *注意*：每句话不要有超过 1~2 处重音，过多会导致语气过激。

### 3. 语速缓急控制 (`[rate]`)
**原则**：人的说话速度不是恒定的，越重要、越抽象、越专业的概念，语速越需要放缓；而例证、背景介绍时可稍快。

- **放缓解密（深刻/凝炼）**：
  - `请大家记住这个数字：[rate:slow]百分之九十八点五[/rate]。`
- **加快带过（列举/轻松）**：
  - `无论你用的是 Mac、Windows 还是 Linux，[rate:fast]都能开箱即用[/rate]。`

### 4. 音高与语气起伏 (`[pitch]`)
**原则**：音高能直接传达说话者的情绪状态。
- **疑问/好奇/惊喜**：适当提升音调（`[pitch:+10%]` 或 `[pitch:high]`）。
  - *范例*：`[pitch:+10%]真的有这么简单吗？[/pitch]`
- **稳重/权威/总结**：适当降低音调（`[pitch:-10%]` 或 `[pitch:low]`）。
  - *范例*：`[pitch:-10%]这就是最终的裁决。[/pitch]`

### 5. 数字、专有名词与读音防踩坑 (`[say-as]` / `[sub]`)
这是普通 Agent 最容易翻车的地方！必须主动拦截：

| 场景 | 原始写法（易读错） | 导演修饰写法（100% 正确） | 说明 |
| :--- | :--- | :--- | :--- |
| **手机/座机电话** | `13800138000` | `[say-as:telephone]13800138000[/say-as]` | 逐位念出号码，数字“1”会正确念为“幺” |
| **验证码/流水号** | `9527` | `[say-as:digits]9527[/say-as]` | 防止被读成“九千五百二十七” |
| **年份** | `2026年` | `[say-as:date]2026年[/say-as]` | 正确读作“二零二六年” |
| **多音字/专有读音** | `重量` vs `重新` | `[sub:chong2]重[/sub]新出发` | 使用 `[sub:读音]` 强制注音 |
| **英文缩写** | `TTS` | `[say-as:characters]TTS[/say-as]` | 逐字母读作“T-T-S”，防止发音成单词 |

## 🎬 经典改写案例对比（Before & After）

### 案例 A：科技产品发布会 / 讲解配音
- **原始死板文本（Before）**：
  > 欢迎使用我们的新产品。它采用了最新的神经网络引擎，处理速度提升了三倍。如果你有任何问题，可以拨打客服电话 4008101234 咨询。
- **配音导演精修文本（After）**：
  > 大家好！[pause:300ms][emphasis:strong]欢迎体验全新一代语音处理平台[/emphasis]。[pause:500ms]它搭载了最新的自研神经网络引擎，[pause:300ms]综合处理速度——[rate:slow][emphasis:strong]整整提升了三倍[/emphasis][/rate]！[pause:800ms]如果您在使用中有任何疑问，欢迎随时致电官方支持热线：[say-as:telephone]4008101234[/say-as]。[pause:400ms]祝您创作愉快！

---

### 案例 B：有声书 / 故事叙述
- **原始死板文本（Before）**：
  > 门吱呀一声开了，外面一片漆黑，什么也没有。李明屏住呼吸走出了房间。
- **配音导演精修文本（After）**：
  > 门，[pause:300ms]吱呀一声开了……[pause:800ms]门外是一片死一般的漆黑，[pause:500ms][rate:slow]什么也没有[/rate]。[pause:1s]李明屏住呼吸，[pause:400ms][pitch:-10%]悄悄走出了房间。[/pitch]

---

### 案例 C：知识科普 / 短视频文案
- **原始死板文本（Before）**：
  > 你知道为什么熬夜会变胖吗？因为缺乏睡眠会导致瘦素分泌减少，而饥饿素会增加 20%，导致你第二天吃得更多。
- **配音导演精修文本（After）**：
  > 你知道为什么熬夜会变胖吗？[pause:600ms]关键原因其实藏在大脑里：[pause:400ms]睡眠不足，会导致体内的瘦素分泌骤减，[pause:300ms]而饥饿素——[rate:slow][pitch:+10%]直接暴增 [say-as:digits]20%[/say-as][/pitch][/rate]！[pause:700ms]这就意味着，[emphasis:strong]不是你想吃，而是身体在逼你吃[/emphasis]！

## 📋 Agent 配音导演自检清单

在将文稿送入语音合成前，请对照自检：
1. [ ] **是否已将电话、验证码、单字符用 `[say-as]` 包裹？**
2. [ ] **疑问句与核心转折点是否有 `[pause:300ms-600ms]` 呼吸停顿？**
3. [ ] **重点观点与品牌词是否添加了 `[emphasis:strong]`？**
4. [ ] **整篇文稿总停顿是否在 30 秒以内、单次停顿是否在 5 秒以内？**
5. [ ] **所有标签（如 `[emphasis]`、`[rate]`）是否全部正确闭合？**（可调用 `tts_client.py --validate` 快速检测）
